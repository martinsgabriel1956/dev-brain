# W3Schools

Site de tutoriais e referência de HTML, CSS e JavaScript, com exemplos editáveis ("Try it Yourself").

- Em [[wiki/sources/seletores-e-pseudo-elements-css]], Násser usa o **Try CSS Selector** (https://www.w3schools.com/cssref/trysel.php, "basta digitar cssref w3schools"): uma página de exemplo (`div.intro` com três `<p>`, `span#Lastname`, `p#my-Address`, uma lista `ul`) em que cada [[wiki/concepts/seletores-css|seletor]] clicado destaca os elementos que pega. A aula o chama de "artigo no W3C".
- Em [[wiki/sources/principais-propriedades-css-color-background-font]], [[wiki/entities/nasser|Násser]] o indica para descobrir os valores de uma propriedade: "vem aqui no W3Schools e pesquisa background-size", ou busca no Google "background-size W3Schools".

`[external]` É de uma empresa privada (Refsnes Data, Noruega) e **não tem ligação com o [[wiki/entities/w3c]]**, apesar do nome. Para a definição normativa e o detalhe de compatibilidade, MDN (https://developer.mozilla.org) e as especificações são as fontes de referência.

## O "W3C" do mini curso de CSS Animations (FrontPUSH)

Em [[wiki/sources/frontpush-propriedade-transform-parte-2-transform-origin-transform-style-preserve-3d]], o slide de `transform-style` copia a sintaxe `flat|preserve-3d|initial|inherit` e as descrições em inglês do W3Schools, que [[wiki/entities/nasser|Násser]] chama de "W3C" ([[wiki/entities/w3c]]).

## Chamado pelo nome no mini curso (FrontPUSH, básico CSS aula 03)

Em [[wiki/sources/frontpush-propriedade-animation-parte-1-keyframes-from-to-duration-direction-fill-mode]], [[wiki/entities/nasser|Násser]] diz "W3Schools" e usa os exemplos "Play it" das páginas de `animation-*` (direction, duration, fill-mode, iteration-count, play-state, timing-function), confirmando que o "W3C" das aulas anteriores era este site.
