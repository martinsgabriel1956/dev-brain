# W3Schools

Site de tutoriais e referências de tecnologias web. Na aula [[wiki/sources/seletores-e-pseudo-elements-css]], Násser usa o **Try CSS Selector** (https://www.w3schools.com/cssref/trysel.php, "basta digitar cssref w3schools"): uma página de exemplo (`div.intro` com três `<p>`, `span#Lastname`, `p#my-Address`, uma lista `ul`) em que cada [[wiki/concepts/seletores-css|seletor]] clicado destaca os elementos que pega. A aula o chama de "artigo no W3C".

`[external]` É de uma empresa privada (Refsnes Data, Noruega) e **não tem ligação com o [[wiki/entities/w3c]]**. Para a definição normativa, MDN e as especificações são as fontes de referência.
