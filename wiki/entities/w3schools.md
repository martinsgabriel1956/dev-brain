# W3Schools

Site de tutoriais e referência de HTML, CSS e JavaScript, com exemplos editáveis ("Try it Yourself"). `[external]` Não tem ligação com o [[wiki/entities/w3c]], apesar do nome. Para a especificação e o detalhe de compatibilidade, a referência mais completa é o MDN (https://developer.mozilla.org).

Em [[wiki/sources/principais-propriedades-css-color-background-font]], [[wiki/entities/nasser|Násser]] o indica para descobrir os valores de uma propriedade: "vem aqui no W3Schools e pesquisa background-size", ou busca no Google "background-size W3Schools".
