# Visual Studio Code

Editor de código da Microsoft.

Em [[wiki/sources/basico-css-o-que-e-sintaxe-inline-incorporado-externo]], é o editor da demonstração do [[wiki/entities/frontpush|FrontPUSH]] (uma aula anterior do curso, não ingerida, configura o editor e os plugins). Dois recursos aparecem: o Emmet, "plugin nativo" que gera a estrutura do HTML5 e a tag `<link>` por abreviação (`[external]` https://code.visualstudio.com/docs/editor/emmet), e a extensão Live Server, que sobe um servidor local e atualiza o navegador a cada Ctrl+S. Ver [[wiki/concepts/setup-live-reload-debug-testes]].
