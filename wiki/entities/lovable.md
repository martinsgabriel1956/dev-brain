# Lovable

Ferramenta de geração de aplicações via IA — principal referência atual para pessoas não técnicas construírem produtos técnicos. Fundada por Ned.

## Por que design importa aqui

O sucesso do Lovable não é só tecnológico — é de **design de produto**. Tornar algo técnico acessível para pessoas não técnicas exige profundo trabalho de design: UX de onboarding, linguagem, feedback de erros, fluxos simples.

## Relevância para Design Engineers

Lovable demonstra que design vai além do visual — é conhecer o público e construir algo direcionado para ele.
