# Discloud

Plataforma de hospedagem/deploy citada em [[wiki/sources/escopo-de-projetos-processo-nao-resultado-lorehub]] como alternativa gratuita para colocar projetos pessoais no ar: plano free, integração direta com GitHub e auto deploy a cada novo commit. Mencionada como recomendação prática para quem já tem um projeto rodando localmente e quer publicá-lo sem começar pagando por infraestrutura — mesmo papel que [[wiki/entities/hostgator]] cumpre em outras fontes da wiki, mas com tier gratuito em vez de VPS paga desde o início.
