# LeetCode

Plataforma de prática de problemas de algoritmos e estruturas de dados, usada tanto para estudo individual quanto como formato de referência para [[wiki/concepts/entrevista-tecnica-coding|entrevistas técnicas de coding]] em empresas de tecnologia. Fornece enunciado completo, exemplos e validação automática de submissões.

A diferença entre praticar no LeetCode sozinho e ser entrevistado ao vivo é central ao framework de preparação documentado em [[wiki/concepts/entrevista-tecnica-coding]]: no LeetCode o candidato recebe o problema "de bandeja" (enunciado, exemplos, dicas), enquanto numa entrevista real essas informações precisam ser extraídas ativamente do entrevistador via perguntas de esclarecimento.

## Convenções de plataforma

Convenção observada em [[wiki/sources/binary-search-em-5-minutos]]: para problemas de busca, o padrão é retornar `-1` quando o elemento buscado não é encontrado no array.
