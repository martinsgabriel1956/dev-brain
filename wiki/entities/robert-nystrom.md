# Robert Nystrom

Autor de *Crafting Interpreters*, livro gratuito e online apontado como o melhor recurso introdutório para quem quer implementar uma linguagem de programação do zero. O livro guia passo a passo a construção de duas implementações completas de uma mesma linguagem, chamada **Lox**:

1. Um interpretador tree-walking em Java (`jlox`).
2. Uma máquina virtual com bytecode em C (`clox`).
