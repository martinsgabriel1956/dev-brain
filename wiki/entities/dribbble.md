# Dribbble

Plataforma de showcase de trabalhos de design. Usada por devs frontend como **fonte de referências visuais** — não para copiar, mas para construir repertório.

## Uso prático

Buscar por componente/layout específico com filtro "web":
- `table design` → referências de tabelas
- `dashboard design` → referências de dashboards
- `login page` → referências de telas de login

O objetivo é pegar **referências de layout e composição**, não copiar. Ver o que profissionais de design resolveram para o mesmo problema.
