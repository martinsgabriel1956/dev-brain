## O Que É

SDK TypeScript da Vercel para chamar LLMs de múltiplos provedores (Anthropic, OpenAI, Google etc.) com uma API unificada. Retorna, junto com o texto gerado, o objeto `usage` com a contagem de tokens de entrada e saída — útil para comparar custo e comportamento de tokenização entre provedores.
