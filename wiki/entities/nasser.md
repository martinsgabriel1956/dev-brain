# Násser

Instrutor de um curso em PT-BR com módulo de UI Design. Não se apresenta como UI designer de carreira: diz que estuda design porque gosta de criar as próprias interfaces e trabalha como freelancer. Recebe perguntas de alunos pelo Instagram e usa o [[wiki/entities/figma]] no curso ([[wiki/sources/como-aprender-ui]]).

Nome confirmado pelo usuário em 2026-11-13; as legendas automáticas transcreveram "Nácia". Sobrenome desconhecido.

Curso: [[wiki/entities/frontpush]]. A ligação, antes inferida, foi confirmada em [[wiki/sources/principios-do-design-eixo-simetria-consistencia-simplicidade]]: o autor diz o próprio nome ("Ah, Násser, como assim?") e mostra o site frontpush.com.br como "a minha interface". Usa o Feather Icons e diz ter posts sobre grids no Instagram.

## Ideias recorrentes

- UI é subconjunto da UX; acertos pequenos de UI se somam ([[wiki/sources/o-que-e-ux-ui-design]]).
- "Criatividade se constrói": copiar, entender o porquê, montar [[wiki/concepts/mood-board]], fazer [[wiki/concepts/redesign-como-exercicio|redesigns]] ([[wiki/sources/como-aprender-ui]]).
- Princípios do design ([[wiki/concepts/eixo-visual|eixo]], [[wiki/concepts/simetria-visual|simetria]], [[wiki/concepts/consistencia-visual|consistência]], [[wiki/concepts/simplicidade-visual|simplicidade]]) antes do conteúdo específico; "o design bonito é aquele consistente" ([[wiki/sources/principios-do-design-eixo-simetria-consistencia-simplicidade]]).
- Boa UI se define pelo negativo e pelo [[wiki/concepts/objetivo-da-interface|objetivo]]; não fugir dos [[wiki/concepts/padroes-de-interface|padrões]] ([[wiki/sources/patterns-o-que-faz-uma-boa-ui-padroes]]).
- Design de interface é antecipar o que o usuário vai precisar fazer; o "depende" vem de [[wiki/concepts/objetivo-da-interface|objetivo]] e [[wiki/concepts/contexto-do-usuario|contexto do usuário]]; saber explicar cada detalhe de uma tela ([[wiki/sources/elementos-da-interface-introducao-ui-design]]).
- Imagem é comunicação construída; peso é acessibilidade; foto → JPG, transparência → PNG, ícone → SVG; tudo passa por compressão ([[wiki/sources/imagens-e-ilustracoes-formatos-bancos-otimizacao]]).
- Fotos de gente real humanizam ("pessoas negociam com pessoas"); um ponto focal por foto; texto em imagem é branco sobre capa de gradiente ([[wiki/sources/imagens-e-ilustracoes-aspect-ratio-pessoas-ponto-focal-texto]]).
- Formas se escolhem pelo que se quer comunicar e se aplicam com consistência: radius de 8 px no FrontPUSH, 3–4 px no Spider-Man, mais redondo no Creator Push ([[wiki/sources/formas-exemplos-praticos-radius-consistencia-projetos]]).
- Imagem acompanha o que está ao lado; padronizar proporção e resolução para o dev; [[wiki/concepts/blend-modes]] no Figma no lugar do Photoshop ([[wiki/sources/imagens-e-ilustracoes-bom-senso-contraste-padronizacao-blend-modes]]).
- Ícone é símbolo de objeto, ação ou ideia; o significado vem do pattern; estilo do ícone segue a identidade visual, uma família por projeto ([[wiki/sources/icones-parte-1-conceito-comunicacao-identidade-visual-familias]]).
- Elementos de composição dão ambiência no fundo, acompanham a branding e nunca roubam o contraste do ponto focal; ajudam a compor empty screens ([[wiki/sources/elementos-de-composicao-ambiencia-background-branding-empty-screens]]).
- Todo elemento comunica ou interage; boa interface = propósito, simplicidade e consistência; cor informa (azul link, vermelho alerta, amarelo warning) ([[wiki/sources/elementos-da-interface-visao-geral-proposito-consistencia-simplicidade]]).
- O espaço depende do meio: conteúdo denso pede menos espaço e mais linhas e cards; prefere escala de espaçamento geométrica à linear; padding deixa o card limpo ([[wiki/sources/espacamento-e-linhas-espaco-vs-meio-sistema-geometrico-padding]]).
- Botões guiam o usuário na jornada; o mesmo botão em toda a interface, primário e secundário, área clicável de 44 px ([[wiki/sources/botoes-e-links-guiar-jornada-consistencia-anatomia-hover]]).
- A forma do botão segue o que se quer comunicar; arredondado é o coringa, circular aproxima, reto dá seriedade ([[wiki/sources/formas-de-botoes-reto-arredondado-circular-chanfrado-diagonal-hexagonal]]).
