# Unreal Engine

Game engine da Epic Games. Em [[wiki/sources/vibe-coding-jogos-um-prompt-vs-varios-estagios-produto]], é a engine escolhida para construir por vibe coding um MVP de jogo de golfe com câmera híbrida 2D/3D (POV lateral no swing, POV da bola em voo). O agente do ChatGPT precisou fazer o setup completo — incluindo login/criação de conta na Epic Games — e escreveu o próprio script para rodar o jogo no Mac.
