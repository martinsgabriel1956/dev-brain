# MDN Web Docs

Documentação de referência de HTML, CSS, JavaScript e APIs do navegador, em developer.mozilla.org. `[external]` Criada pela Mozilla; hoje mantida pela Mozilla com o Open Web Docs e outros parceiros. Cada página traz uma tabela de compatibilidade e, desde 2023, o selo Baseline ([[wiki/concepts/compatibilidade-entre-navegadores]]).

Em [[wiki/sources/frontpush-o-que-e-html-linguagem-de-marcacao-tags-semantica]], [[wiki/entities/nasser|Násser]] a indica como "o próprio MDN da Firefox [...] uma página muito boa para poder a gente entender essas coisas", ao lado do "W3C" ([[wiki/entities/w3c]]). É a fonte de quase todos os `[external]` das páginas de front-end desta wiki.
