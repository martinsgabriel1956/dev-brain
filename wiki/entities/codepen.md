# CodePen

Editor online (codepen.io) com painéis de HTML, CSS e JavaScript e prévia que atualiza sozinha.

Em [[wiki/sources/nlw-1-dia-2-media-queries-formulario-javascript-ecoleta]], [[wiki/entities/mayk-brito|Mayk Brito]] o usa para o "beabá" de JavaScript: "ele fica rodando sozinho", "não preciso salvar, não preciso clicar em ctrl s", embora "às vezes isso causa algum bug". O pen travou depois de muito uso e foi resolvido recarregando e colando o código de volta. O código foi guardado em `scripts/intro.js` do projeto.

## Sass vs SCSS no FrontPUSH

Em [[wiki/sources/frontpush-introducao-sass-pre-processador-sass-vs-scss]], [[wiki/entities/nasser|Násser]] liga o pré-processador nas configurações de CSS do pen ("save and close") para comparar CSS, Sass indentado e SCSS. A internet lenta atrasou a compilação.
