# Greg Young

Criador do padrão [[wiki/concepts/cqrs|CQRS]] (Command Query Responsibility Segregation), derivado de um conceito anterior, CQS (Command Query Separation). Também autor da ideia de **Command Sourcing** — armazenar os comandos originais (não só os eventos resultantes) para permitir re-executar o mesmo comando sob um contexto de negócio diferente, apresentada numa palestra e citada como pouco aplicada na prática.
