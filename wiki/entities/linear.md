# Linear

Ferramenta de gestão de projetos e issues reconhecida como **referência máxima de design e performance frontend**. Não há dev frontend que não cite o Linear como benchmark de qualidade.

---

## Por que é Referência

- **Velocidade:** navegação e interações instantâneas — aplicação funciona como app nativo no browser
- **Design de interação:** cada clique, hover e transição é pensado; demonstração prática de [[concepts/design-como-interacao]]
- **Acessibilidade:** funciona bem em múltiplos contextos
- **Offline-first:** arquitetura que prioriza responsividade local antes de sincronização

---

## Para Devs Frontend

Se você nunca usou o Linear, use ao menos uma vez para calibrar o padrão de qualidade de interação. É o equivalente de ver o código de um sistema bem arquitetado — eleva seu senso crítico sobre o que é possível.
