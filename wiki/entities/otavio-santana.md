# Otávio Santana

## Quem É

Engenheiro de software brasileiro experiente, com atuação notável na comunidade Java. Participa de bate-papos técnicos em português com outros engenheiros seniores.

## Contribuições relevantes para o wiki

Em [[wiki/sources/filosofia-design-software-podcast-eduardo-matos-otavio-santana-mauricio-linhares]], discute *A Philosophy of Software Design* de [[wiki/entities/john-ousterhout]] junto com [[wiki/entities/mauricio-linhares]]:

- Conecta o sintoma de onboarding lento e falta de documentação ao problema de complexidade não encapsulada (ver [[wiki/concepts/sintomas-de-complexidade-ousterhout]]).
- Cita a API de I/O do Java como exemplo canônico e recorrente de má API, discutido até hoje pelo comitê executivo do Java como erro de design reconhecido pela própria comunidade.
- Aponta um erro comum na aplicação do padrão Repository (DDD): usar nomes de método genéricos de CRUD em vez de vocabulário do domínio (ver [[wiki/concepts/repository-pattern]], [[wiki/concepts/ddd]]).
- Escolhe o Cap. 10 do livro ("Define Errors Out of Existence") como o trecho mais importante para todo engenheiro conhecer — ver [[wiki/concepts/define-errors-out-of-existence]].
