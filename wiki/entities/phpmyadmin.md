# phpMyAdmin

Aplicação web em [[wiki/entities/php]] para administrar MySQL e MariaDB pelo navegador: tabelas, consultas SQL, importação e exportação, usuários `[external]` (https://www.phpmyadmin.net; alta). Vem no [[wiki/entities/xampp]] e no [[wiki/entities/cpanel]].

No [[wiki/entities/frontpush|FrontPUSH]] ([[wiki/sources/frontpush-hostgator-parte-2-cpanel-recursos-ftp-ssl-email]]): "um programinha que facilita eu criar banco de dados com uma interface gráfica, sem precisar utilizar terminal"; "já utilizei muito ele". No cPanel, o banco e o usuário são criados em "Bancos de dados MySQL"; o phpMyAdmin entra depois, para mexer no conteúdo ([[wiki/concepts/mysql]]).
