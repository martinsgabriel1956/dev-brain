# TanStack

Organização open-source criada por Tanner Linsley. Mantém um ecossistema de bibliotecas agnósticas de framework focadas em problemas de UI de alta performance.

## Principais Projetos

| Projeto | Descrição |
|---|---|
| TanStack Query | Server state, cache, fetch |
| TanStack Table | Tabelas headless, sorting, filtering |
| TanStack Router | Roteamento type-safe |
| TanStack Form | Formulários performáticos |
| TanStack Virtual | Virtualização de listas |
