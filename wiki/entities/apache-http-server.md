# Apache HTTP Server

Servidor web open source que dominou os anos 90; o nome viria de *a patchy server* (remendos aplicados via `diff`/`patch` — segundo o autor). Módulos embutidos permitiram PHP no núcleo ([[wiki/concepts/servidor-web-vs-servidor-de-aplicacao]], [[wiki/concepts/cgi-common-gateway-interface]]). Hoje Nginx é o citado como servidor web.
