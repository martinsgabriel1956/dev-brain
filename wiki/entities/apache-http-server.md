# Apache HTTP Server

Servidor web open source que dominou os anos 90; o nome viria de *a patchy server* (remendos aplicados via `diff`/`patch` — segundo o autor). Módulos embutidos permitiram PHP no núcleo ([[wiki/concepts/servidor-web-vs-servidor-de-aplicacao]], [[wiki/concepts/cgi-common-gateway-interface]]). Hoje Nginx é o citado como servidor web.

## FrontPUSH, hospedagem aula 03

Em [[wiki/sources/frontpush-website-estatico-vs-aplicacao-web-php-apache-xampp-react]]: "o PHP precisa do Apache para rodar"; ligado no [[wiki/entities/xampp]] nas portas 80 e 443, o FrontPUSH em [[wiki/entities/php]] abre. Quem executa o PHP é o interpretador, acoplado via `mod_php` ou PHP-FPM.
