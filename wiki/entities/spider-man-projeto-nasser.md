# Spider-Man (projeto do Násser)

"Um outro projeto meu" de [[wiki/entities/nasser]], com style guide próprio. Não se sabe se é estudo, fan site ou trabalho para cliente ([[wiki/sources/formas-exemplos-praticos-radius-consistencia-projetos]]).

O projeto tem um card na interface do [[wiki/entities/frontpush]], que Násser usa como exemplo de card com os mesmos 8 px de radius do botão do FrontPUSH. Isso sugere que o Spider-Man aparece no site como um dos projetos do curso (inferência).

## Formas: fora da caixa

O oposto deliberado do [[wiki/entities/frontpush]]: "mais entusiasta", feito para chamar a atenção saindo do padrão. Recursos: traços retos levemente arredondados (3–4 de [[wiki/concepts/border-radius|radius]]), elementos e quadradinhos "deitados" como itálicos, muita transparência, botões e grids "chanfrados". Tudo aplicado com [[wiki/concepts/consistencia-visual|consistência]], como "parte de uma mesma família".

## Elemento de composição: textura

Aqui a ambiência vem de uma textura alinhada à identidade visual e de fotografia, com alguns elementos no hover dos links ([[wiki/sources/elementos-de-composicao-ambiencia-background-branding-empty-screens]]). Ver [[wiki/concepts/elementos-de-composicao]].

## Botões chanfrados no jogo

Em [[wiki/sources/formas-de-botoes-reto-arredondado-circular-chanfrado-diagonal-hexagonal]], o autor cita o "novo jogo do Homem-Aranha" (o jogo, não este projeto) como exemplo de botão chanfrado ou hexagonal, de caráter futurista. Combina com os elementos inclinados e o raio de 3–4 px do projeto (inferência).
