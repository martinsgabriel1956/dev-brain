# Rinha de Backend

Desafio online e open source onde desenvolvedores implementam o mesmo projeto — independente de linguagem de programação ou banco de dados — para comparar performance e acurácia das implementações. Usado como exemplo prático em [[wiki/sources/3-pilares-testes-automatizados-produtividade]] para demonstrar a técnica de [[wiki/concepts/mapear-entrada-processamento-saida]]: uma web API que registra transações de crédito/débito de um cliente e guarda o histórico, com regras de validação de limite e saldo.
