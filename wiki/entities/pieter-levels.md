# Pieter Levels (Levelsio)

Indie hacker de referência para quem constrói produtos sozinho (sem equipe/investimento externo); fatura, segundo [[wiki/sources/levelsio-china-guardrails-multi-modelo-opus-5]], ~3 milhões de dólares por ano com múltiplos SaaS, incluindo o Photo AI (relatado em ~140.000 USD/mês no ano anterior, caindo para ~90.000 USD/mês). Publicou no próprio blog (28/06/2026) que codifica usando Claude Code diretamente na VPS de produção há quase um ano — sem ambiente de staging intermediário, aceitando downtime ocasional como custo operacional.

## Incidente com Guardrails do Claude (Kimi K3 vs. Claude)

Twittou (17/07/2026) que o [[wiki/entities/moonshot-ai|Kimi K3]] completou sua lista de tarefas de um projeto hobby (simulador de Windows XP) enquanto o Claude Code perdeu duas semanas em fricção com [[wiki/concepts/ai-safety-guardrails|guardrails de segurança]] — incluindo rebaixamento de modelo (Opus → Sonnet) "por segurança" no meio da sessão. Migrou para usar Opencode com Kimi K3 via Kimi Server (chave de API própria, ~19 USD, sem throttling a cada 5 minutos como percebido no Claude Code). Relatou também que o Claude respondeu com um "sermão" de saúde a uma pergunta rotineira sobre um exame de sangue (razão monócitos/linfócitos) — episódio usado por [[wiki/entities/lucas-montano]] como evidência de guardrail excessivamente condescendente/paternalista.
