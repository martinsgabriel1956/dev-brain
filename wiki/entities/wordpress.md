# WordPress

CMS open source em [[wiki/entities/php]] com banco MySQL/MariaDB, o software mais instalado em hospedagem compartilhada; painéis como o [[wiki/entities/cpanel]] o instalam em poucos cliques `[external]` (https://wordpress.org; alta).

No [[wiki/entities/frontpush|FrontPUSH]]:
- Aula 04 ([[wiki/sources/frontpush-hostgator-parte-1-plano-turbo-name-servers-registro-br]]): o cPanel serve para "instalar o WordPress", entre outras coisas.
- Aula 05 ([[wiki/sources/frontpush-hostgator-parte-2-cpanel-recursos-ftp-ssl-email]]): "esses servidores [...] vêm muito preparados para o WordPress"; para quem trabalha com WordPress ou PHP, o autor indica HostGator ou Hostinger, "sem precisar pegar em absolutamente nada de código ou linha de comando".
