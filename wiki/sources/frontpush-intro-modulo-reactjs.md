# Introdução ao módulo de ReactJS (FrontPUSH)

## TL;DR

Aula 01 do módulo de ReactJS do [[wiki/entities/frontpush|FrontPUSH]], cerca de 48 segundos, sem código. [[wiki/entities/nasser|Násser]] (autoria pela sequência: ele diz que "também fiz" o módulo de JavaScript ES6+) abre o módulo de [[wiki/entities/react|React]].

- **"Módulo de biblioteca JavaScript":** aqui o React é chamado de biblioteca, não de framework ([[wiki/concepts/framework-web]]).
- **Atraso:** agradece "pela paciência de terem esperado". O módulo foi prometido antes e saiu depois.
- **Método:** "todos os principais conceitos" mais exemplos e projetos práticos "para poder a gente fixar" ([[wiki/concepts/proporcao-8020-estudo-pratica]]).
- **Pré-requisito:** o módulo de [[wiki/entities/javascript|JavaScript]] [[wiki/concepts/ecmascript|ES6+]] foi feito para dar os conceitos que o React "vai meio que dar continuidade". Fecha o ciclo aberto em [[wiki/sources/frontpush-introducao-javascript-es6-ecmascript]].

## Key Claims

- O React é "aquele módulo de biblioteca JavaScript que eu falei que iria ministrar aqui no curso". Evidência: fala de abertura; a promessa anterior não aparece nas aulas já ingeridas.
- "Garanto que eu dei o meu melhor para poder passar todos os principais conceitos, bem como rechear de projetos ou de exemplos práticos e de projetos práticos para poder a gente fixar todo o conhecimento." O método declarado é conceito mais prática.
- "Eu também fiz um módulo específico para JavaScript ES6+ para poder a gente aprender os conceitos de JavaScript que a gente vai meio que dar continuidade aqui no ReactJS." Confirma que o módulo de JS é preparação do de React, como dizia a aula 01 de JS ("nivelar [...] antes de [...] o React").

## Precisões e tensões com a wiki

- **Biblioteca, agora.** Na aula 01 de JavaScript ele disse "alguma framework, como, por exemplo, o React". Aqui diz "biblioteca JavaScript", que é como a documentação do React se descreve ("The library for web and native user interfaces", https://react.dev/) `[external]`. A entidade [[wiki/entities/react]] já registra que ele não inclui roteamento nem estado global por padrão. `[skill: tech-mentor-frontend]` Na prática, a própria documentação atual recomenda começar por um framework (Next.js, React Router), e a distinção pesa menos que antes. Confiança alta.
- **"ES6+".** A legenda diz "S6 Plus"; corrigido para ES6+, o nome do módulo usado nas outras aulas ([[wiki/concepts/ecmascript]]).
- **Data da gravação.** Sem pista de versão do React nesta aula. Pelo resto do FrontPUSH, o período provável é 2020–2021 (React 16.x/17, Hooks já existentes, antes do React 18 de março de 2022) (inferência). `[skill: tech-mentor-frontend]` Hoje o React está na linha 19 (`use()`, Actions, React Compiler); conferir nas próximas aulas o que mudou, por exemplo se o projeto começa com create-react-app (descontinuado em fevereiro de 2025) em vez de Vite ou um framework.
