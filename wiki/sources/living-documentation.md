# Living Documentation

## TL;DR

Documentação gerada automaticamente a partir do código ou testes — nunca fica desatualizada porque é gerada no CI. Distinção crítica: living documentation quebra o build se ficar desatualizada, ou é gerada automaticamente eliminando a possibilidade de divergir. Oposto de um Confluence cheio de páginas que ninguém atualiza.

## Claims Principais

| Claim | Confiança |
|---|---|
| Doc manual inevitavelmente diverge do código | Alta |
| Testes bem escritos são a melhor documentação do comportamento esperado | Alta |
| OpenAPI gerado de annotations nunca fica desatualizado | Alta |
| Structurizr DSL: diagramas C4 versionados no repositório | Alta |
