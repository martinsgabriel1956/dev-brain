# Windows

Sistema operacional de desktop da Microsoft, lançado pela primeira vez em 1985 (Windows 1.0) como interface gráfica sobre o MS-DOS. É o sistema mais amplamente utilizado do mundo, com versões marcantes como Windows 95, XP, 7, 10 e 11.

## Vantagens

- Roda em praticamente qualquer PC/notebook de qualquer fabricante — ampla compatibilidade de hardware.
- Executa uma faixa larga de cargas: jogos pesados, escritório, programação.
- Interface amigável, baixa barreira de entrada para iniciantes.

## Desvantagens

- Requisitos de sistema pesados deixam hardware antigo/fraco lento.
- Atualizações frequentes e por vezes invasivas (loops de atualização).
- Maior alvo de vírus e malware por ser o SO mais instalado do mundo.
- Kernel panic do Windows é a Tela Azul da Morte (BSOD) — ver [[wiki/concepts/kernel]].

## Kernel

Windows NT é um [[wiki/concepts/kernel|kernel]] híbrido (monolítico com elementos de microkernel).
