# Teoria das cores

Estudo de como as cores se formam, se combinam e o que comunicam. Em UI, responde às perguntas que os alunos mais fazem: que cores usar, como aplicar gradientes, como destacar para causar contraste ([[wiki/sources/teoria-das-cores-introducao-natureza-objetivos-fenomeno-fisico]]).

## Os quatro blocos da abertura do módulo

| Bloco | O que entra | Página |
|---|---|---|
| Inspiração na natureza | composição, cores análogas e gradientes, complementares | [[wiki/concepts/harmonia-de-cores]] |
| Objetivos das cores | contraste, hierarquia, informação, estilo, categorização, identidade | [[wiki/concepts/contraste]], [[wiki/concepts/hierarquia-visual]], [[wiki/concepts/cor-semantica]], [[wiki/concepts/psicologia-das-cores]] |
| Fenômeno físico | espectro de 400 a 700 nm, a cor é da luz | [[wiki/concepts/espectro-visivel]] |
| Representação em códigos | HSB, hexadecimal, RGB x CMYK | [[wiki/concepts/modelos-de-cor]] |

## Subjetiva, mas com princípios

Para [[wiki/entities/nasser|Násser]], cor "tem um caráter subjetivo muito grande", mas segue princípios; o guia dele é a natureza. Cor é um dos [[wiki/concepts/elementos-da-interface]], mas densa o bastante para um módulo próprio. Regra prática de proporção: [[wiki/concepts/regra-60-30-10]].

`[skill: ux-ui-mentor]` Cor em UI é sistema, não estética: cada cor tem um papel (primitivos → semânticos → componente).
