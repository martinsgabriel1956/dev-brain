# Referência Relativa de URI

Forma de citar um recurso **sem escrever o endereço completo**, a partir do contexto do documento atual (ex.: dentro de um site, apontar para outra página só pelo caminho). É o exemplo da fonte de que uma [[wiki/concepts/uri|URI]] **não precisa conter localização de rede completa** — identifica o recurso, mas só se torna uma [[wiki/concepts/url|URL]] localizável completa quando resolvida contra uma base.

- [external] RFC 3986 §4.2 define "relative reference" e o algoritmo de resolução contra a URI base. https://www.rfc-editor.org/rfc/rfc3986#section-4.2
