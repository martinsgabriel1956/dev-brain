# Ciclo de Revisita

Estrutura de aprendizado espiral em que as mesmas etapas de [[wiki/concepts/onboarding-de-codebase]] são repetidas com profundidade crescente a cada volta — em vez de percorrer cada etapa uma única vez até "terminar".

## A lógica espiral

Cada volta pelo ciclo acontece com mais contexto que a anterior:
- **1ª volta:** documentação cria primeiro mapa, código parece denso, tarefas são difíceis
- **2ª volta:** documentação faz mais sentido, código tem familiaridade, tarefas fluem melhor
- **N-ésima volta:** documentação revela nuances antes invisíveis, app vira janela transparente para o código

Não é repetição mecânica — é [[wiki/concepts/aprendizado-por-impressoes]] intencionalizado numa estrutura.

## Quando começar a segunda volta

Após completar uma tarefa real e escrever testes relacionados. O momento certo é quando a curiosidade por "como isso funciona mais profundamente" aparece naturalmente.

## Contribuição à documentação como fechamento do ciclo

Uma volta completa termina quando você consegue contribuir com algo que estaria faltando para a *sua versão passada*: um diagrama, um guia interno, um passo que estava faltando no README. Isso fecha o ciclo e inicia o próximo.

## Relação com [[wiki/concepts/pratica-deliberada]]

O ciclo de revisita é prática deliberada aplicada ao aprendizado de sistemas — não repetição passiva, mas exposição progressiva com intenção e feedback.
