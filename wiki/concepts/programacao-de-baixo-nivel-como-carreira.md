# Programação de Baixo Nível como Caminho de Carreira

## TL;DR

Trabalhar perto do processador e do SO (onde rodam inclusive sistemas web) é um mundo que a maioria dos devs não acessa. Diferença-chave: **recurso é escasso e controlado o tempo todo**, o que muda como se programa e se pensa. Fonte: [[wiki/sources/senioridade-nao-e-so-tecnica-especializacao-negocio-dados-confianca-em-crise]].

## Ideias

- "Entender" Bluetooth/threads ≠ usar uma biblioteca JS; é saber desenvolver o **driver**.
- Na programação web a preocupação com recursos existe, mas é de nível muito menor.
- **Não é sinônimo automático de mais sênior** — é um eixo entre vários ([[wiki/concepts/senioridade-por-especializacao]]).
- Exemplo do autor: perspectiva de [[wiki/entities/linus-torvalds]]; contraste com o foco de [[wiki/entities/uncle-bob]] no dia a dia.
