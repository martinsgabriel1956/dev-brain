# Dopamina e Projetos

O cérebro libera mais dopamina na **antecipação da recompensa** do que no recebimento dela. Para devs: a fase de ideação ("cara, vou construir isso!") é quimicamente mais prazerosa do que a fase de construção. Isso cria um ciclo viciante de iniciar projetos sem terminar nenhum.

## O Mecanismo

```
Ideia nova → dopamina alta (antecipação)
Construção → dopamina cai (trabalho real)
Nova ideia → dopamina alta novamente
→ abandono do projeto anterior
```

Não é falta de disciplina — é bioquímica. A solução não é "ter mais força de vontade"; é redesenhar o ambiente para que a recompensa dopaminérgica venha de **completar tasks**, não de iniciar projetos.

## Consequência Prática

- "Graveyard de projetos" no GitHub não é anomalia — é o padrão esperado sem intervenção consciente
- Quanto mais promissora a ideia parece, mais dopamina na fase de planejamento, maior o risco de abandonar o projeto atual

## Mitigação

1. **[[concepts/goal-gradient-effect]]** — micro-tasks que geram dopamina ao serem completadas
2. **[[concepts/mvp]]** — escopo mínimo reduz o gap entre ideação e entrega
3. **Regra do "termine antes de começar"** — não iniciar projeto novo enquanto o atual não atingiu MVP
