# Código como Commodity

Tese de que escrever código deixou de ser diferencial porque LLMs produzem código bom em abundância e a baixo custo. Quem tinha as linhas de código como único valor perde a vantagem, e o valor migra para decidir **o quê** construir, especificar e verificar. Ver [[wiki/sources/tendencia-vale-do-silicio-programador-generalista-vs-especialista]].
