# Style guide

Documento com as decisões visuais de uma interface (cores, tipografia, botões, estados, sombras) para aplicá-las de forma consistente.

## No processo de wireframes

Em [[wiki/sources/wireframes-parte-3-passo-a-passo-fidelidade-escala-de-cinza-segredo]], o style guide é o último passo: o "protótipo final com o auxílio dos style guides". Lá entram as cores auxiliares, onde vai gradiente, o [[wiki/concepts/contraste]] entre as cores e o alinhamento ao branding, além de "cada decisão de tela, de botão, de comportamento, de cores e animação". O [[wiki/concepts/wireframe]] cinza fica fora disso de propósito. Ver [[wiki/concepts/fidelidade-de-prototipo]]. É anunciado como o próximo tópico do curso.

## Citado em outras aulas

- O hover do botão, uma [[wiki/concepts/sombra-em-interfaces|sombra]] suave na cor da marca, deve ficar "muito bem claro no meu style guide" ([[wiki/sources/botoes-pratica-figma-padding-gradiente-contraste-smooth-shadow]]); ver [[wiki/concepts/feedback-do-sistema]].
- Os padrões de tamanho de texto ficam para a [[wiki/concepts/tipografia]] e para o style guide da parte de interfaces web, que vai ficar para download (mesma fonte).

`[skill: ux-ui-mentor]` Um style guide é a camada documental de um design system: sem tokens e componentes em código, ele descreve; com eles, vira fonte única de verdade.
