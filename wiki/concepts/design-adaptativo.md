# Design Adaptativo

Layouts distintos, desenhados para cada [[wiki/concepts/breakpoint]], em vez de um layout fluido que se estica. Em [[wiki/sources/grids-pratica-2-material-de-apoio-bootstrap-material-design-flexbox-grid]], o autor diz que responsivo e adaptativo "são dois conceitos diferentes", já explicados na teoria (não ingerida), e indica um artigo "para vocês complementarem esses conhecimentos ou até me corrigirem se eu estiver errado".

## Responsivo x adaptativo

`[skill: ux-ui-mentor]`

| | [[wiki/concepts/design-responsivo\|Responsivo]] | Adaptativo |
|---|---|---|
| Abordagem | Layout fluido que se ajusta | Layouts distintos por breakpoint |
| Controle | Menor | Maior |
| Complexidade | Menor | Maior |
| Quando usar | Maioria dos casos | Experiências muito diferentes entre devices |

## Na aula

Os exemplos que ele mostra misturam os dois: o grid fluido ("conforme aumenta a tela também, aumenta o sistema de grids") é responsivo; o formulário da home que vira "um botãozinho" no mobile é uma decisão de layout por tela, mais perto do adaptativo. Classificação do agente.
