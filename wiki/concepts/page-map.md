# Page Map

O "flow das dobras, das seções" de uma página: a ordem em que cada seção aparece "a cada seção que eu vou descendo no meu site" ([[wiki/sources/wireframes-parte-1-o-que-e-uso-foco-page-map-papel-e-caneta]]). [[wiki/entities/nasser|Násser]] chama as dobras de "minhas telinhas". O page map nasce "um pouco antes do wireframes" e acompanha o [[wiki/concepts/wireframe]] desde a baixa fidelidade.

## Para que serve

- **Montar a jornada do usuário** como "um passo a passo" para entender o produto ou serviço, em acordo com os objetivos (slide). Ver [[wiki/concepts/objetivo-da-interface]].
- **Não deixar pontas soltas:** algo citado numa dobra precisa ser explicado em outra.
- **Posicionar os gatilhos** de uma página de vendas. Ver [[wiki/concepts/design-persuasivo]].

Exemplo da aula: página de vendas de um curso online, com vídeo de apresentação → diferencial → depoimentos → estrutura do produto → quem dá a aula → bônus → chamada para cadastro.

## Page map não é sitemap

Na aula, "page map" e "site map" aparecem juntos. `[skill: ux-ui-mentor]` Sitemap é a árvore de páginas de um produto (navegação, arquitetura de informação). O page map é a sequência de seções dentro de uma página, mais perto de um roteiro de conteúdo de landing page. Um site de várias páginas teria um sitemap e um page map por página.

## Relação com outros conceitos

- [[wiki/concepts/wireframe]]: o page map ordena as dobras que o wireframe desenha.
- [[wiki/concepts/ux-design]]: a jornada do usuário dentro de uma página.
- [[wiki/concepts/hierarquia-visual]]: a ordem das dobras é a hierarquia no eixo da rolagem (leitura não dita na aula).
