# Page map

A lista ordenada das seções de uma página, montada antes do [[wiki/concepts/wireframe]]. Na aula, [[wiki/entities/nasser|Násser]] monta o page map "para poder me guiar e depois construir os wireframes que condizem com esse page map" ([[wiki/sources/wireframes-parte-2-briefing-objetivo-page-map-leitura-f-z]]). O slide diz "Construir o flow, o pagemap".

## De onde vem

1. Do [[wiki/concepts/objetivo-da-interface]]: "você precisa conhecer qual é o objetivo principal para que você construa o flow, o site map, o page map, a interface, os wireframes".
2. Dos [[wiki/concepts/padroes-de-interface|patterns]] do tipo de página, achados por "observação e pesquisa" em sites como o [[wiki/entities/ui-movement]].
3. Das perguntas que o usuário faz: numa página de venda, "são as perguntas que o usuário faz quando ele está comprando um produto online".

## Exemplos da aula

- **Portfólio:** começa pela seção de hero, que diz "para o que trata o website, qual é o serviço", com "uma headline objetiva e direta, depois um parágrafo mais detalhado abaixo".
- **[[wiki/entities/frontpush]]:** apresentação do produto, detalhes do produto e o CTA "quero me inscrever" repetido pela página. "Eu simplesmente segui isso no page map e montei o meu estilo."
- **Pricing:** seção de planos em escada (standard ou prata, depois gold).

## Site map x page map

A aula usa os dois termos sem definir. Leitura desta página (inferência): o site map é a árvore de páginas do site; o page map, a ordem das seções dentro de uma página. `[skill: ux-ui-mentor]` A skill (`references/fluxos-ia.md`) documenta sitemaps como árvore de páginas e separa fluxo de tarefa (passos lineares) de fluxo de usuário (com decisões e erros).
