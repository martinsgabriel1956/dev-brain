# Problema com Solução

Comportamento de **trazer problemas ao gestor sempre acompanhados de pelo menos uma sugestão de solução**. Distingue quem quer resolver de quem quer apenas se queixar.

## O ciclo da reclamação viciosa

```
Cultura fechada → empresa proíbe reclamações (ruim)
Cultura aberta  → empresa permite reclamações (avanço)
                → mas alguns ficam viciados em só reclamar (nova doença)
```

Identificar problemas é a metade mais fácil. Propor soluções é a metade que cria valor — e que a maioria não faz.

## Por que isso importa para a carreira

Quem leva problemas com sugestões:
- Ganha espaço e credibilidade
- É visto como agente de solução, não de ruído
- Constrói histórico de influência mesmo sem autoridade formal

## O custo de propor solução

Propor uma solução coloca sua credibilidade em risco se ela não funcionar. Isso é intencional — é o preço da influência. Quem nunca propõe nunca erra e nunca cresce.

## Formato prático

```
❌ "O processo de deploy está quebrado."

✅ "O processo de deploy está causando X problema.
   Minha sugestão é Y. Teria 30 minutos para discutir?"
```

## Relação com Extreme Ownership

[[extreme-ownership]] diz que o líder assume responsabilidade pelos problemas. "Problema com solução" é a aplicação disso na comunicação ascendente — não só descendente.
