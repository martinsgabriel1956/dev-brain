# Soft Skills

Habilidades humanas que permitem colaborar, resolver problemas e se adaptar a diferentes contextos. Não substituem as [[wiki/concepts/hard-skills-vs-soft-skills|hard skills]] — as potencializam.

## Por Que Importam em Tech

Tecnologia é feita de pessoas. Dois devs com o mesmo nível técnico terão trajetórias radicalmente diferentes dependendo de como se comunicam, colaboram e se adaptam. Soft skills são o multiplicador sobre a base técnica.

## Relação com Hard Skills

Hard skills abrem a porta. Soft skills determinam o quanto você avança depois de entrar. Em níveis Senior+, a diferença de impacto entre dois profissionais competentes tecnicamente é quase inteiramente explicada pelas soft skills.
