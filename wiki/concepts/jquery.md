# jQuery

Biblioteca JavaScript criada em 2006 por [[wiki/entities/john-resig]] para resolver a fragmentação de implementações de DOM e JavaScript entre navegadores da época (Firefox vs. Internet Explorer vs. outros). Tarefas simples — selecionar elementos, manipular HTML, fazer uma requisição Ajax — exigiam código extenso e conhecimento específico das diferenças entre engines. jQuery ofereceu uma API única para manipulação de DOM, eventos, animações e chamadas assíncronas, sob o lema "write less, do more".

## Auge (2007–2013)

Adoção quase universal em projetos web, turbinada por um ecossistema de plugins (jQuery UI, jQuery Mobile, DataTables) e pelas primeiras versões do Bootstrap, que dependiam de jQuery.

## Por que perdeu espaço

Dois movimentos simultâneos, a partir de meados dos anos 2010: (1) navegadores passaram a seguir padrões web com muito mais consistência, reduzindo a necessidade de uma camada de compatibilidade; (2) o próprio JavaScript absorveu boa parte do que só jQuery oferecia, com o ECMAScript 2015 (ES6). Em paralelo, frameworks baseados em componentes e gerenciamento de estado ([[wiki/entities/react]], Vue, Angular) mudaram o paradigma de construção de interface, reduzindo ainda mais o espaço do jQuery em projetos novos.

## Por que ainda está em produção

Extremamente presente em aplicações corporativas, sistemas internos e portais construídos ao longo da última década. Raramente escolhida para projetos novos, mas segue com manutenção ativa — release estável em 17/01/2026, quase 20 anos após seu lançamento.
