# Cientista de Dados vs. Engenheiro de Dados

## TL;DR

Dados se dividiram em papéis muito diferentes, e há subdivisões dentro de cada um. Fonte: [[wiki/sources/senioridade-nao-e-so-tecnica-especializacao-negocio-dados-confianca-em-crise]].

| | Cientista | Engenheiro |
|---|---|---|
| Base | Estatística e matemática | Engenharia de acesso/serving |
| Pergunta | O modelo é assertivo para *este* negócio? | Como servir dado rápido, com alta disponibilidade e custo controlado? |
| Diferencial | Criatividade, conhecimento de negócio, ser questionador | Estrutura que atende muita gente sem cair nem ficar cara |

## Notas

- Sem conhecer a área, o cientista precisa questionar e entender a empresa; quanto mais ímpeto de entender a fundo, melhores os modelos (conecta com [[wiki/concepts/especialista-de-dominio-de-negocio]]).
