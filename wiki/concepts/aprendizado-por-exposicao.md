# Aprendizado por Exposição

Método de aprendizado baseado em expor-se à maior quantidade possível de exemplos reais antes de tentar produzir algo original. A fluência emerge da [[wiki/concepts/pattern-recognition|detecção de padrões]] acumulada pela exposição repetida — não do estudo de regras.

## Como Aplicar em Programação

1. Abrir um repositório do GitHub de um lado, editor do outro.
2. Copiar código manualmente — não colar, **digitar**.
3. Sem objetivo de produto. O único objetivo é acumular horas de contato com código real.
4. Fazer isso com código de pessoas e projetos diferentes.
5. Quebrar o código copiado. Ver o que acontece.

A [[wiki/concepts/memoria-muscular|memória muscular]] se forma com a repetição. Padrões de nomenclatura, tamanho de funções, estrutura de arquivos — tudo começa a se fixar antes de qualquer compreensão explícita.

## Analogias

- **Aprender português**: ninguém decora gramática primeiro. Você ouve, imita, erra, corrige gradualmente.
- **Datilografia**: Akita copiava enciclopédias múltiplas vezes — não pelo conteúdo, mas pela sensação de ganhar velocidade e perceber padrões de composição de texto.
- **Desligar as legendas**: assistir filmes em inglês sem legenda é desconfortável mas acelera a aquisição.

## O que NÃO é aprendizado por exposição

- Fazer um projeto do zero do começo ("projetinho do zero" como receita padrão).
- Seguir um tutorial passo a passo sem desviar.
- Decorar sintaxe antes de ver como ela aparece em código real.

## Distinção Crítica com o Uso Passivo de IA

Exposição ativa (copiar, digitar, quebrar, observar padrões) é diferente de [[aprendizado-passivo]] (copiar e colar código gerado por IA sem processar).

A diferença: na exposição ativa, o esforço de digitação e modificação força o cérebro a processar o padrão. No copiar e colar passivo, o código passa direto para o editor sem construir nenhuma representação mental.

Usar IA para **mostrar alternativas** ou **exemplos de padrões** é exposição ativa. Copiar a solução sem entender é aprendizado passivo.

## Relação com [[repertorio]]

Aprendizado por exposição é o mecanismo pelo qual o [[repertorio]] se constrói. Cada hora de exposição ativa a padrões reais de código deposita um fragmento de repertório. Com acúmulo suficiente, esses fragmentos se conectam em reconhecimento instantâneo de padrões — o que o programador experiente chama de "intuição".
