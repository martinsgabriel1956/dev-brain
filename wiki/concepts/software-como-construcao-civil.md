# Software como Construção Civil

**TL;DR:** Analogia de Balta: sistemas são como casas (térrea, sobrado, subsolo...), nunca a mesma; frameworks dão o alicerce pronto e a IA vai "subir o muro".

## Usos

1. Explicar por que o prompt precisa dizer qual casa se quer ([[wiki/concepts/prompt-vago-vs-prompt-especifico-demais]]).
2. Explicar por que falta base a quem só usou frameworks ([[wiki/concepts/fundamentos-e-teoria-na-era-da-ia]]).
