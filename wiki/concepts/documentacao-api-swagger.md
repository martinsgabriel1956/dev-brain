# Documentação de API com Swagger/Scalar

Gerar documentação de API automaticamente é um diferencial raro: aproximadamente 1 em 10 devs se preocupa com isso em projetos de portfólio.

## O que é

- **Swagger/OpenAPI**: especificação que descreve todas as rotas, métodos, parâmetros e respostas da API
- **Scalar**: interface open source de visualização mais moderna que o Swagger UI padrão

## O mínimo para portfólio

Uma rota `/docs` que exibe a API reference completa:
- Todas as rotas disponíveis
- Métodos HTTP (GET, POST, PUT, DELETE)
- Parâmetros e schemas de request/response
- Possibilidade de testar as rotas direto na interface

Não precisa de diagramas ou documentação narrativa — API reference é suficiente.

## Por que diferencia

Demonstra que o candidato pensa em quem vai consumir a API, não só em quem vai implementar. É visível imediatamente ao abrir o projeto.
