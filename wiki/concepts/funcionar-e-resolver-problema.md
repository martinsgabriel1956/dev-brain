# Funcionar é Resolver o Problema do Usuário

Para o dev, "funciona" costuma ser *sem exception e com mensagem de sucesso*; para o usuário, **funcionar é resolver o problema dele** — e não travar/errar é pré-requisito óbvio (senão ele troca de software). Aprender só o primeiro sentido gera o conflito que vira bronca e [[wiki/concepts/inseguranca-na-entrega]]. Ver [[wiki/concepts/o-certo-e-um-combinado]], [[wiki/concepts/definicao-de-pronto]], [[wiki/entities/andre-casciotti]].
