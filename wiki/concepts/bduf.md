# BDUF — Big Design, Up Front

Termo do glossário do xUnitPatterns.com ([[wiki/entities/gerard-meszaros]]), com verbete próprio dedicado em [[wiki/sources/bduf-xunitpatterns]]: a abordagem clássica **"waterfall"** (cascata) para design de software, onde todos os requisitos precisam ser entendidos no início do projeto e o software é projetado para suportar todos eles numa **única fase de design**, antes de qualquer código ser escrito — o oposto formal de [[wiki/concepts/emergent-design|emergent design]], onde o design certo é descoberto incrementalmente à medida que o software evolui para passar um teste de cada vez em [[wiki/concepts/tdd|TDD]].

## Key Sources

- [[wiki/sources/bduf-xunitpatterns]] — **fonte primária dedicada**: define o termo diretamente ("classic waterfall approach... single design phase") e nomeia o oposto formal, [[wiki/concepts/emergent-design|emergent design]]
- [[wiki/sources/emergent-design-xunitpatterns]] — cita BDUF como o oposto formal de emergent design, sem definir o termo diretamente
