## Definição

Padrão estrutural que converte a interface de uma classe em outra interface esperada pelo cliente. Permite que classes com interfaces incompatíveis trabalhem juntas.

## Diferença do Proxy

O Adapter muda a interface. O [[proxy-pattern]] mantém a mesma interface — apenas intercepta e adiciona comportamento.
