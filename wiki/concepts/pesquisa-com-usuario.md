# Pesquisa com o usuário

Perguntar, observar e validar com quem vai usar o produto antes e durante o desenho. Para [[wiki/entities/nasser|Násser]], no módulo de dashboards, é "inerente a todo esse processo": é com o usuário que se decide o que ganha destaque na [[wiki/concepts/hierarquia-visual]] ([[wiki/sources/frontpush-dashboards-principios-parte-1]]).

- **No levantamento de requisitos:** "sempre pergunte ao usuário, qual que é o aspecto mais importante para você?" ([[wiki/concepts/requisitos-funcionais-e-nao-funcionais]], [[wiki/concepts/briefing]]).
- **Iterando:** "em sucessivas reuniões, é interessante você mostrar, perguntar a opinião dele", com o fluxo em andamento.
- **Contexto:** "qual o dia a dia seu, o que você mais faz", para posicionar as informações ([[wiki/concepts/contexto-do-usuario]]).
- **O que vai em destaque:** "a informação [...] que ele tá sempre utilizando com mais frequência", "quais são os principais dados que [o CEO usa] para poder fazer a tomada dessas decisões".

`[skill: ux-ui-mentor]` Perguntar o que é importante (opinião) é diferente de observar o que a pessoa faz (comportamento); para dashboards, ver o usuário usando a ferramenta atual costuma revelar mais do que a entrevista. Mostrar o fluxo e pedir opinião aproxima-se de um [[wiki/concepts/teste-de-usabilidade]] informal.
