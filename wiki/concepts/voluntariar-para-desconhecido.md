# Voluntariar para o Desconhecido

Oferecer-se para tarefas que você não sabe fazer — deixando claro que não sabe, mas vai encarar.

## Por que Funciona

Ativa o "circuito do triunfo": desafio → conquista → reconhecimento. Um júnior que peita missão desconhecida é visto com respeito pela coragem — mesmo sem resolver tudo. Volta com conhecimento novo de qualquer forma.

## Não Tem Data de Validade

Cada projeto é um mundo novo: pessoas novas, requisitos novos, frameworks novos. Quem evita o desconhecido nunca fica confortável começando projetos novos. O hábito vale para sêniors também.

## Como Aplicar

- Gerencie expectativas: "Nunca fiz isso, mas quero aprender."
- Não finja que sabe.
- Se travar, use [[concepts/pair-programming]] para kickoff.
