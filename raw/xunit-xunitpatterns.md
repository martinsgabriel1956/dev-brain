# xUnit

> Tradução para português do verbete de glossário **"xUnit"**, do site xUnit Patterns.
> Fonte: http://xunitpatterns.com/xUnit.html
> Autor: Gerard Meszaros | Copyright © 2003-2008
> Verbete de glossário do livro *xUnit Test Patterns: Refactoring Test Code* (2007).
> Tradução feita para fins de estudo.

O nome genérico para qualquer **Framework de Automação de Testes** (*Test Automation Framework*) de **teste de unidade** (*unit testing*) baseado no padrão do **JUnit** ou **SUnit**.

O framework de teste *xUnit* para a maioria das linguagens pode ser encontrado em http://xprogramming.com ou http://en.wikipedia.org/wiki/XUnit. Outro lugar para procurar tanto ferramentas de **teste de unidade** (*unit test*) quanto de **teste de cliente** (*customer test*) é http://www.opensourcetesting.org.
