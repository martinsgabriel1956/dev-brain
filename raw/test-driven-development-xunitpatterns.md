# test-driven development (TDD)

Fonte original: xUnitPatterns.com — Glossário

Desenvolvimento orientado a testes (test-driven development) é um processo de desenvolvimento que consiste em escrever e automatizar os testes unitários (unit tests) antes que o desenvolvimento das unidades correspondentes seja iniciado. Isso garante que as responsabilidades de cada unidade de software sejam bem compreendidas antes de serem codificadas.

Diferente do test-first development, o test-driven development normalmente implica que o código de produção (production code) é feito para funcionar um teste de cada vez — uma característica chamada de design emergente (emergent design).

Ver também: storytest-driven development.
