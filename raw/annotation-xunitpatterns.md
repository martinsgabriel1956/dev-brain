Uma forma de indicar algo sobre algo. O **JUnit** versão 4.0 usa *annotations* (anotações) para indicar quais classes são **Testcase Classes** e quais métodos são **Test Methods**; o **NUnit** usa **attributes** (atributos).

## Termos relacionados

- **JUnit** — framework de testes para Java que introduziu o uso de anotações (`@Test`, etc.) na versão 4.0 para marcar classes e métodos de teste.
- **NUnit** — framework de testes para .NET que usa atributos (`[Test]`, etc.) com o mesmo propósito.
- **Testcase Class** — classe que agrupa Test Methods relacionados.
- **Test Method** — método que implementa um único test case.
- **attribute** — mecanismo equivalente às annotations, usado no ecossistema .NET/NUnit.
