# Block

> Tradução para português do verbete **"Block"**, do site xUnit Patterns (categoria "Glossary").
> Fonte: http://xunitpatterns.com/block.html
> Autor: Gerard Meszaros | Copyright © 2003-2008
> Padrão do livro *xUnit Test Patterns: Refactoring Test Code* (2007).
> Tradução feita para fins de estudo.

Um bloco de código que pode ser executado. Muitas linguagens de programação (mais notavelmente Smalltalk e Ruby) usam blocos (também conhecidos como "block closures") como uma forma de passar um trecho de código para um método, que pode então executá-lo em seu próprio contexto. As "classes internas anônimas" (anonymous inner classes) do Java são uma forma de alcançar o mesmo efeito sem suporte direto a *blocks*. C# usa "delegates" para alcançar um propósito semelhante.
