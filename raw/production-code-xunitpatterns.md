# Production Code

> Tradução para português do verbete **"production code"**, do site xUnit Patterns.
> Fonte: http://xunitpatterns.com/production%20code.html
> Autor: Gerard Meszaros | Copyright © 2003-2008
> Termo do livro *xUnit Test Patterns: Refactoring Test Code* (2007), categoria "Glossary".
> Tradução feita para fins de estudo.

Eu precisava de um termo para distinguir o código de teste do código que estamos testando. "**Test code**" (código de teste) é óbvio. Como chamar o outro tipo de código? Em ambientes de TI, o ambiente no qual as aplicações rodam é frequentemente chamado de **production** (produção). Por isso, escolhi chamar o código que escrevemos, seja para embarcar em um produto ou para implantar em **production**, de "*production code*" (código de produção). Assim, temos **test code** e temos "*production code*".
