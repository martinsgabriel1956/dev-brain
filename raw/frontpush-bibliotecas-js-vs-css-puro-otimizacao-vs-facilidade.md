## O que faz o CSS

A primeira coisa que a gente precisa entender é o que faz o JavaScript, o que faz o CSS, qual a diferença entre eles, o que cada um deles faz.

Só para lembrar, pessoal, que é o CSS que manipula todo e qualquer elemento de Motion, utilizando as propriedades de scale, que geralmente é a propriedade de transform, onde eu posso aumentar e diminuir o objeto, posso deixar ele opaco, totalmente transparente ou visível. Mas eu quero que você entenda que quem faz essa manipulação é o CSS.

Vou abrir o código que eu estou pedindo nesse keyframe. Olha, em um primeiro momento, no começo da animação, eu quero que ele não apareça esse objeto, ou seja, opacidade zero. No começo dessa animação, eu quero que a escala desse objeto seja 30% do seu tamanho original. E ao final dessa animação, que é uma animação que eu quero que apareça, appear em inglês, eu quero opacidade 1, ou seja, que ele não esteja transparente, que ele não esteja opaco e que a escala dele seja 100% da original.

## O que faz o JavaScript

Então, o que o JavaScript faz, se ele também faz motion? Porque, gente, lembre-se que o JavaScript evoluiu tanto que já não é só uma linguagem de marcação ou de estilo, como é o CSS, porque o CSS também é uma tecnologia muito moderna. Só que o JavaScript é uma linguagem propriamente dita de programação, se ele é uma linguagem de programação e consegue manipular a árvore DOM de elementos do HTML, consequentemente, ele consegue englobar o CSS, então, meio que o JavaScript consegue mandar no CSS.

E pelo fato dele ser uma linguagem de programação, eu consigo inserir a lógica de forma mais acentuada no JavaScript, que é utilizar de condições, de estruturas de repetição, de matemática, de bibliotecas de matemática, de outras bibliotecas que facilitem eu, por exemplo, administrar algum tipo de valor, ou, então, tratar essas propriedades de CSS como escala, como translado, como rotação, de maneira mais fácil.

Só que pela inteligência que você pode agregar na biblioteca, parece que é algo que você não está utilizando o CSS, mas lá no fundo, no fundo, no fundo, é CSS, o JavaScript manipula o CSS de maneira mais inteligente, pelo fato de ser uma linguagem de programação, só isso.
