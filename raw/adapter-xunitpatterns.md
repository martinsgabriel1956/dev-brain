**Objetivo:** Converter a interface fornecida por um objeto para outra, esperada por um cliente.

Converte a interface de uma classe em outra interface que os clientes esperam. Adapters permitem que classes trabalhem juntas mesmo quando, de outra forma, não poderiam, devido a interfaces incompatíveis.
