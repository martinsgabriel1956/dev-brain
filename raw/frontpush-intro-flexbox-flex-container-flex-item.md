## Flex-container e flex-itens

Vamos ver aqui, basicamente a gente está dividido em dois estudos. Quando a gente define o Flexbox, você precisa entender das propriedades que remetem ao flex-container e das propriedades que remetem aos flex-itens.

Então, a gente vai aprender o que cada uma dessas aqui significa, como a gente faz para aplicar e construir layout responsivo.

## Para que serve o Flexbox

Onde, já reitero, eu devia até ter dito isso lá no começo da aula, para que serve o Flexbox?

Ele serve para layout.

A gente tratou aqui no CSS básico um pouco de estilização, o básico de box-model, as principais propriedades. Então essas partes aqui, a estilização é literalmente utilização do CSS básico; a parte de Flexbox é construir layout responsivo, é construir o esqueleto de forma que eu possa colocar o conteúdo e que ele se adapte ao tamanho da tela.
