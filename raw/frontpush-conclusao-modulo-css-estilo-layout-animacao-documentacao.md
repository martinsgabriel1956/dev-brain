## HTML é conteúdo, CSS é estilo e layout

O que é de mais imprescindível que você entenda é o HTML e CSS para poder você ter como base e entender os próximos conteúdos, tanto de projetos práticos como de outros módulos que a gente fala de outras seções, de outros recursos do CSS. Mas basicamente você aprendeu que HTML é uma linguagem de marcação e que serve para poder a gente definir o nosso conteúdo. A gente insere o nosso conteúdo, a gente constrói a nossa estrutura de tags no HTML.

No CSS você vai olhar para o HTML e aí você vai estilizar tanto literalmente colocar cores, tipografia, modificar a forma das coisas, mas também você vai adicionar layout, outra funcionalidade do CSS. Você consegue construir o seu layout responsivo que se adapta à tela, ou seja, para telas maiores, para telas menores, ele se adapta utilizando só CSS, sem utilizar nenhuma outra tecnologia, apenas recursos da tecnologia nativa que o browser entende.
