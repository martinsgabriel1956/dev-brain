# JMock

Um framework de **Mock Object** dinâmico amplamente utilizado para testes em Java. A fluente **Configuration Interface** usada para especificar as expectativas torna os testes altamente legíveis. Mais informações podem ser encontradas no site do *JMock*: [http://www.jmock.org](http://www.jmock.org).

## Metadados do artigo

- Entrada curta do catálogo de ferramentas ("Tools") do site xUnitPatterns.com, de Gerard Meszaros (autor do livro *xUnit Test Patterns: Refactoring Test Code*).
- Página gerada originalmente em 09/02/2011 (conteúdo do site é anterior, provavelmente de meados dos anos 2000).
- Tema central: JMock é catalogado como uma implementação do padrão **Mock Object**, com destaque para sua **Configuration Interface** fluente (API de especificação de expectativas via method chaining) como diferencial de legibilidade dos testes.
- Contexto: parte da taxonomia de padrões de teste (xUnit Patterns) de Meszaros, que cataloga ferramentas conhecidas como exemplos concretos de padrões descritos no livro (ex: Mock Object, Configurable Test Double).
