## Interface dinâmica e interface estática

Um outro ponto muito importante é que o React é voltado para a criação de interface dinâmica, interface do usuário, então tudo que está no front, essa biblioteca é utilizada e vocês vão entender, porque a gente vai desenvolver muito desses conceitos ao longo das próximas aulas, mas o primeiro ponto que eu quero destacar aqui com vocês é, por exemplo, a diferença, deixa eu até aumentar aqui minha tela, é a diferença entre o que é uma interface dinâmica e uma interface estática.

Ao contrário do que eu já vi algumas pessoas falarem para mim que uma interface dinâmica é aquela que detém algum tipo de motion, a página sendo carregada com a biblioteca GSAP ou elementos de carregamento, e não é isso. Vamos, pessoal, por exemplo, a gente tem uma seção de motion design aqui no curso onde a gente trabalha essas skills, mas quando eu falo da diferença de uma interface dinâmica e uma interface estática, não está aí.

Uma interface dinâmica é aquela que, por exemplo, eu tenho várias rotas e tem como eu, por exemplo, ter uma página e ela ser reconstruída de maneira diferente dependendo da rota que eu clico para o usuário. É aquela página web que me oferece uma funcionalidade, então necessariamente são aquelas páginas que detêm de JavaScript ou uma linguagem de programação por trás.

O que seria uma interface estática é aquela que eu não consigo agregar a funcionalidade, ou seja, um site com HTML e CSS só. Com essas duas tecnologias, eu não consigo criar interfaces dinâmicas e o React.js pega essa ideia de construir interfaces dinâmicas e eleva para outro nível e eu vou dar um pequeno exemplo aqui para vocês.

## Single-page application, abordagem declarativa e Virtual DOM

E aí, pessoal, a gente já falou sobre interfaces dinâmicas, qual é a diferença dele do estático e single-page application, nesse caso eu só vou citar aqui as principais características porque, de fato, é uma questão muitíssimo importante a gente entender esse conceito de single-page application, por que tem esse nome, quais são as suas principais características, onde eu posso falar, por exemplo, que o React vai utilizar uma abordagem declarativa, o que significa isso?

Basicamente, ele atualiza apenas os componentes necessários, pensa lá naquele exemplo do Facebook que eu dei, quando você abre o chat online e você manda uma mensagem, você vai perceber que ele atualiza, por exemplo, somente o chat, o resto da sua página ele não recarrega para poder carregar, por exemplo, uma mensagem, então eu meio que consigo seccionar a minha página e fazer da minha página, ela baseada em componentes, que é um outro conceito que a gente vai tratar aqui, então assim eu consigo maior performance.

Uma outra característica do React é que ele utiliza o virtual DOM, a gente sabe que, por exemplo, quando a gente está falando de interface web, a gente precisa entender e lembrar o que é a árvore DOM de elementos, que nada mais é do que o HTML e a estrutura propriamente dita da nossa página, onde ela precisa estar sempre atualizando, porque quando eu clico em alguma coisa, ela precisa ser modificada para poder apresentar esse conteúdo ao usuário, mas o React utiliza um conceito que a gente vai ver também nas próximas aulas, que é o virtual DOM, que ele primeiro faz uma cópia virtual, se é que eu posso dizer assim, para poder comparar quais são as reais modificações antes de fazer propriamente dita a renderização, isso a gente ganha performance, porque ele está carregando não a página inteira, mas pequenas seções que são os componentes, eu consigo atualizar os componentes e a gente vai ver como é que funciona isso na prática.
