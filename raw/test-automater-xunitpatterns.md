# test automater

> Tradução para português do verbete de glossário **"test automater"**, do site xUnit Patterns.
> Fonte: http://xunitpatterns.com/test%20automater.html
> Autor: Gerard Meszaros | Copyright © 2003-2008
> Verbete de glossário do livro *xUnit Test Patterns: Refactoring Test Code* (2007).
> Tradução feita para fins de estudo.

A pessoa ou o papel do projeto responsável por construir os **testes**.

Pode existir um "especialista no domínio" (*subject matter expert*) responsável por definir quais testes devem ser criados, para que sejam automatizados pelo *test automater*.
