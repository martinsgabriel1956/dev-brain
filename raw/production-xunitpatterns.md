# Production

> Tradução para português do verbete **"production"**, do site xUnit Patterns.
> Fonte: http://xunitpatterns.com/production.html
> Autor: Gerard Meszaros | Copyright © 2003-2008
> Termo do livro *xUnit Test Patterns: Refactoring Test Code* (2007), categoria "Glossary".
> Tradução feita para fins de estudo.

Em ambientes de TI, o ambiente no qual as aplicações usadas por usuários reais são executadas é frequentemente chamado de "**Production**" (produção). Isso serve para distingui-lo dos diversos ambientes de teste, como "acceptance" (aceitação), "integration" (integração), "development" (desenvolvimento), "qual" (abreviação de "quality assessment or assurance", avaliação ou garantia de qualidade), etc.
