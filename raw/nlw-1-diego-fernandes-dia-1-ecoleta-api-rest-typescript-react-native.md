## React Native e Expo

A gente vai entender, para finalizar o dia de hoje, por que a gente vai utilizar React Native e por que a gente vai utilizar uma outra ferramenta também chamada Expo e como que elas funcionam por baixo dos panos, como é que a gente consegue utilizar JavaScript para criar aplicações móveis para Android e iOS nativas, com interface nativa. De um lado a abordagem que você já deve conhecer, que é a abordagem tradicional, onde a gente vai desenvolver um aplicativo móvel, nós precisamos criar um aplicativo para iOS e um aplicativo para Android. O iOS, geralmente, a gente escreve em Objective-C ou até os mais recentes em Swift. O Android, mesma coisa para Java e Kotlin, tranquilo? E aí, lá no iOS, a gente acaba gerando um executável no final, que a gente chama de IPA, né, que é a extensão do arquivo. e no Android nós temos o APK, que a gente envia lá para a Google Play Store e os usuários podem baixar.

Então, na abordagem tradicional, a gente cria uma aplicação para iOS e outra para Android. Isso não quer dizer que o código é convertido para Objective-C, Swift, Java ou Kotlin. Não tem nada disso. No React Native, nenhum código é convertido para uma linguagem nativa. Então quando a gente utiliza o React Native, todo o código é feito em JavaScript. E esse código ele não é convertido em código nativo como a gente já falou, ele não é transpilado.
