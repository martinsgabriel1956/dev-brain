## O que é Motion Design

Primeira coisa que eu queria tratar nessa aula é explicar de maneira bem simples o que é Motion Design.

Eu sei que é algo que dá para deduzir pelo próprio nome, a gente vê mesmo cedo do inglês, é bem claro, o design é como se fosse o gráfico, é algum tipo de desenho, algum tipo de forma em que ela está em movimento, Motion, movimento.

Então, um conceito bem simples aqui é o gráfico em movimento no espaço da tela e no tempo.

Uma coisa que eu queria deixar muito bem claro é que a gente vai estar trabalhando Motion Design para web, então é propriamente dito, utilizando as tecnologias que o browser entende, que é HTML, CSS e JavaScript, sendo mais otimizado para poder executar no browser, nas nossas interfaces.
