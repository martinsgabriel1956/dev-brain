## O que é JavaScript

Com relação à linguagem JavaScript, o que é o JavaScript? O JavaScript, então, pessoal, é uma linguagem de programação em si, diferente, por exemplo, do HTML e do CSS, o HTML é uma linguagem de marcação, onde você insere o conteúdo da página, o CSS é mais voltado para estilização, então esses dois não têm muita inteligência, apesar de que o CSS tenha evoluído tanto que não sei se eu posso falar isso, mas entende o que eu estou querendo dizer e o JavaScript é a linguagem de programação que torna, por exemplo, uma página web dinâmica, é uma tecnologia que implementa funcionalidade naquela página.

"Násser, como assim, me deu um exemplo", por exemplo, vamos supor que você está codando uma página de um e-commerce, você percebe que quando você está listando os produtos no e-commerce, quando você clica em um determinado produto, onde só tem uma fotinha dele pequena lá e uma pequena descrição, quando você clica vai aparecer uma página com maiores descrições, com códigos, com o preço, por exemplo, quantas vezes você pode dividir, com botão de compra, com mais fotos em resoluções maiores, com observações, com fórum e tudo mais.

Então você percebe que a página, a partir do clique, se torna dinâmica, porque se você clicar em um, ele carrega um determinado produto, se você clicar em outro, ele carrega outro produto, outra página, você percebe que essa dinamicidade, quem faz por trás dela é o JavaScript, enquanto a parte visual é responsável, quem a parte de frente de usuário está em contato direto com o usuário, quem é o responsável é o front-end e aquele que vai lá no banco de dados, que constrói as funcionalidades e tudo mais, quem faz isso é o back-end, está bom?

Então a junção desses carinhas faz com que a gente construa uma página web que seja dinâmica, então o JavaScript é essa linguagem de programação que dá a funcionalidade. Para a web não existe só o JavaScript, existem outras tecnologias, mas o JavaScript é uma delas e tem crescido justamente por quê? Porque você aprende uma tecnologia, que é o JavaScript, e você consegue tanto trabalhar essa mesma sintaxe, esse mesmo jeito de trabalhar, aprendendo a mesma tecnologia, tanto no front-end como no back-end, está bom? Como em outras bibliotecas, como o React Native, que é mais voltado para mobile, e por isso que o JavaScript vem crescendo e tem essa vantagem, está bom?
