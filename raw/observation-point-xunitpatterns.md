# observation point

> Tradução para português do verbete de glossário **"observation point"**, do site xUnit Patterns.

> Verbete de glossário do livro *xUnit Test Patterns: Refactoring Test Code* (2007).
> Tradução feita para fins de estudo.

Um *observation point* é a forma pela qual o teste inspeciona o estado do *[[system under test (SUT)]]* após o exercício (*post-exercise state*). É um tipo de *[[interaction point]]*. Alguns *observation points* são fornecidos estritamente para os testes; eles não devem ser usados pelo *[[production code]]*, pois podem expor detalhes de implementação privados do *SUT* que não podem ter garantia de que não mudarão.
