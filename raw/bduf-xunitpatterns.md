## BDUF

"Big Design, Up Front" ("Grande Design, Antecipado") é a abordagem clássica "waterfall" (cascata) para design de software, onde todos os requisitos precisam ser entendidos no início do projeto, e o software é projetado para suportar todos esses requisitos em uma única "fase" de design. Contraste isso com o *emergent design* (design emergente), favorecido por projetos ágeis.

---

## Original (inglês)

"Big Design, Up Front" is the classic "waterfall" approach to software design where all the requirements must be understood early in the project and the software is designed to support all those requirements in a single design "phase". Contrast this with the emergent design favored by agile projects.
