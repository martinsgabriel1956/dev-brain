## O que é o Sass

Então, sem mais delongas, vamos lá, o que é o Sass? O Sass é um pré-processador de CSS, significa que ele é simplesmente um programa que vai dar recursos para o nosso CSS, do que o CSS normal, padrão, uma linguagem de estilização não tem, que são o quê? Skills de linguagem de programação.

Então, como eu escrevi aqui, ele vai melhorar a nossa performance, não é que ele vai fazer algo além do que o CSS já é capaz de fazer, mas ele é um pré-processador que compila o CSS, onde a gente pode ter skills melhoradas de programação, o que melhora demais a nossa produtividade, a nossa organização no código. Calma se você não entendeu direito, nós vamos trabalhar isso ao longo do curso e vocês vão ver o quão poderoso é ter um pré-processador que nos ajuda no nosso trabalho em si. Então o uso do Sass vai aumentar a sua produtividade no CSS.
