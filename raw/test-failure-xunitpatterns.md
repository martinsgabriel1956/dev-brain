# test failure

> Tradução para português do verbete de glossário **"test failure"**, do site xUnit Patterns.

> Autor: Gerard Meszaros | Copyright © 2003-2008
> Verbete de glossário do livro *xUnit Test Patterns: Refactoring Test Code* (2007).
> Tradução feita para fins de estudo.

Uma *test failure* (falha de teste) ocorre quando um *[[test]]* é executado e o resultado real (*actual outcome*) não corresponde ao resultado esperado (*expected outcome*). Contraste com *[[test error]]* e *[[test success]]*.
