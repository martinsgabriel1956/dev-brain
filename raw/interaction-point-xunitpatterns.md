# interaction point

> Tradução para português do verbete de glossário **"interaction point"**, do site xUnit Patterns.
> Fonte: http://xunitpatterns.com/interaction%20point.html
> Autor: Gerard Meszaros | Copyright © 2003-2008
> Verbete de glossário do livro *xUnit Test Patterns: Refactoring Test Code* (2007).
> Tradução feita para fins de estudo.

Um *interaction point* é um ponto no qual um teste interage com o *[[system under test (SUT)]]*. Um *interaction point* pode ser tanto um *[[control point]]* quanto um *[[observation point]]*.
