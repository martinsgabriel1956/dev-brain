# method attribute

> Tradução para português do verbete de glossário **"method attribute"**, do site xUnit Patterns.
> Fonte: http://xunitpatterns.com/method%20attribute.html
> Autor: Gerard Meszaros | Copyright © 2003-2008
> Verbete de glossário do livro *xUnit Test Patterns: Refactoring Test Code* (2007).
> Tradução feita para fins de estudo.

Um **attribute** colocado num método no código-fonte para dizer ao compilador ou ao sistema em tempo de execução que esse método é "especial". Em algumas variantes de **xUnit**, *method attributes* são usados para indicar que um método é um **Test Method**.
