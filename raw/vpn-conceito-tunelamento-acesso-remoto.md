# VPN: Conceito e Tunelamento

VPN significa, em português, "rede privada virtual" (Virtual Private Network). O nome carrega o próprio conceito: ela é **privada** porque tem acesso restrito, e é **virtual** porque se utiliza da infraestrutura de uma rede pública — como a internet — para trafegar dados criptografados, num processo conhecido como **tunelamento**, onde se cria um túnel virtual para transportar dados criptografados relacionados àquele acesso desejado.

Juntando a parte teórica: a VPN é uma rede de acesso restrito de uma organização que usa a infraestrutura de uma rede pública, como a internet, para transmitir seus dados de forma criptografada, por tunelamento.

## Exemplo: matriz e filial

Imagine a matriz de uma empresa tentando se conectar com a filial dessa mesma empresa, em cidades diferentes. As duas querem conectar suas redes, mas sem correr o risco de perda de dados ou vazamento de informações enquanto os dados circulam entre matriz e filial.

Se a empresa decide usar a própria internet para transmitir os dados entre matriz e filial, fica a dúvida se isso é seguro. A resposta é usar uma VPN: cria-se um túnel virtual — um processo de tunelamento — na infraestrutura da rede pública (a internet) para trafegar dados criptografados exclusivos dessa empresa.

Essa é a ideia central de uma VPN: permitir um acesso privado e criptografado usando a infraestrutura da rede pública (internet), criando esse túnel virtual, esse tunelamento.

## Uso para driblar restrição geográfica

Outro uso comum hoje em dia: muita gente usa VPN para acessar conteúdo sem restrição geográfica. Por exemplo, alguém vai para a China, onde diversos recursos do Ocidente são bloqueados. Usando uma VPN, é possível fazer esse acesso através de um provedor de VPN — o usuário fica "escondido" atrás dessa VPN, como se o próprio provedor estivesse acessando o recurso. Isso permite contornar locais que restringem acesso a determinados recursos por localização geográfica — também uma utilização comum de VPN.
