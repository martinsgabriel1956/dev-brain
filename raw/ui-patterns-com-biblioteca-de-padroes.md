## Introdução

Padrões de design de interface são soluções recorrentes para problemas comuns de design. São pontos de referência padrão para o designer de interface experiente.

Padrões de design persuasivo são estratégias recorrentes, baseadas em psicologia, que conduzem deliberadamente o usuário a resultados pretendidos. Dão ao designer um arcabouço sistemático para influenciar com propósito, mantendo o alinhamento com os objetivos da organização e o valor para o usuário.

Padrões de design oferecem uma linguagem comum entre designers. Nomear um padrão carrega mais significado do que o nome em si, o que permite debater alternativas.

Mergulhe nos padrões abaixo para aprender uma linguagem comum de web design.

Todos os caminhos abaixo são relativos a https://ui-patterns.com. Cada categoria tem sua página em `/patterns/<categoria>/list`.
