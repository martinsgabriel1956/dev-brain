## UI Design

Então, vamos lá, UI Design significa User Interface Design, então UI, User Interface do inglês, ou seja, é a forma com que o usuário interage com os dispositivos.

É aquela clássica história de como eu vou interagir com o hardware, com o dispositivo, se eu não tiver um software, e esse software é inerente a ele ter uma interface, uma interface onde eu vou inserir dados, onde eu vou colocar dados para processamento e ele vai me devolver determinada resposta e por assim vai.

E aí a gente começa a ver que User Interface Design não é só websites, não é só telas de aplicativos ou tudo mais, tudo que é inerente a um dispositivo e detém dessa necessidade de interação com o usuário, é um dispositivo sendo utilizado por um usuário, sempre vai ter uma interface ali acoplada a ele, tá bom?

Então, a gente vai estudar elementos que compõem essa interface para poder a gente conseguir antecipar problemas e conseguir melhorar a experiência do usuário na questão de interface. Então, a gente vai estudar quais são os elementos que compõem para poder construir uma interface o mais agradável para ser utilizada possível.

Então, quais são os pontos que a gente vai estudar? Tipografia, ícones, como aplicar espaçamento entre elementos, ilustrações, imagens, como é que eu aplico elas na interface, teoria das cores, formas, quais formas eu devo utilizar, o que eu estou comunicando quando eu estou utilizando aquela forma, quando eu estou utilizando determinada cor, o que eu estou comunicando ou não com ela, dados as devidas proporções, já adianto para vocês que o design em si, se você souber fazer de fato e aplicar determinados princípios, você pode fugir [de] algumas regrinhas. Então, tome conta de tudo que eu vou falar nesse curso aqui, como um direcionamento, mas não leve ao pé da letra de fato, botões, links e etc.

Além de aprender conceitos importantíssimos que são inerentes ao design, que é manter consistência, contraste, saber criar hierarquia para poder a gente construir interface que seja boa de se usar, que não canse o usuário de fato.

Então, o UI designer está justamente preocupado com esses pontos aqui, em estudar esses pontos e desenvolver boas interfaces visuais.

## UX Design

Agora, quando a gente começa a falar de UX design, eu poderia apresentar aqui dois conceitos principais que podem variar de conforme a ótica você está olhando.

Se a gente for pegar só o termo UX, ele significa user experience, também do inglês, ou seja, experiência do usuário. Então, se diz respeito à experiência do usuário ao ele interagir com determinado produto ou serviço.

Então, você vê que se a gente for pelo lado desse conceito, tudo é experiência, concorda comigo? Eu ir em um supermercado e, por exemplo, pegar uma fila ao invés de ter oportunidade de pagar pelo aplicativo ou um delivery, se o supermercado estiver muito cheio, ele pode me trazer uma experiência negativa e é de um produto ou serviço, concorda comigo? Então, avaliando o UX design por essa ótica, ele é um termo mais abrangente.

Porém, existe uma outra ótica que é mais ligada ao profissional de UX designer, uma profissão de fato, o UX designer. Então, se eu fosse falar para você, UX é como se fosse aquele cara que resolve o problema e é o problema como um todo.

Ah, Násser, como assim?

Que ele vai além de apenas proporcionar uma boa experiência para o usuário, porque quando a gente fala de prestar serviço, criar um produto, o usuário é sim, talvez, a ponta onde a gente deve muito observar para poder tomar as melhores decisões possíveis. Mas ele não é a única ponta, tem a ponta, por exemplo, da empresa, se é possível construir determinado produto, tem a viabilidade do próprio produto, se ele é necessário ou não, quais são os pontos ou não, e do próprio usuário.

Então, saiba qual a ótica que você está utilizando aí. O que eu vou tratar aqui é o UX dentro do UI, então é importante aprender e compreender esse conceito que eu estou te falando.
