**Indique algo sobre uma classe implementando uma interface vazia.**

> O padrão *Marker Interface* usa o fato de uma classe implementar uma interface para indicar um atributo booleano semântico da classe. Funciona particularmente bem com classes utilitárias que precisam determinar algo sobre objetos sem assumir que eles são instância de nenhuma classe específica.
