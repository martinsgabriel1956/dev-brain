## O método SPA

Agora quando a gente vai falar de como funciona um SPA, a gente vai começar a ver o que acontece debaixo dos panos quando acontece uma requisição e quais são as vantagens da gente estar utilizando o método do SPA nesse sentido, então vamos supor que é exatamente o mesmo e-commerce só que agora é feito dessa forma aqui, onde eu faço uma requisição para o servidor, ele vai fazer uma requisição para o banco de dados, ele vai me devolver essas informações e agora o servidor não vai renderizar o HTML, o CSS, o JavaScript e vai me entregar esse pacote completo, ele vai me entregar somente a informação do produto, então não tem aquela query que ele pegou lá do banco de dados que me fala o nome do produto, a quantidade, a descrição, ele vai organizar isso em um arquivo chamado JSON, que o JSON significa JavaScript Object Notation, ou seja, é meio que uma forma universal de todas as linguagens se comunicarem e aí ele vai me passar só o que de fato importa, que é a informação, que é o que muda no meu visual, vocês vão perceber, que quando eu abro aqui a parte dos produtos, olha só, o jeito da página é o mesmo, talvez mudou essa parte aqui, mas a estrutura é a mesma, só mudaram as informações, então ele me manda o que de fato importa, que são as informações do produto e aí ele me manda uma linguagem universal que eu posso, por exemplo, pegar no meu front-end o JSON, interpretar ele e aí sim eu consigo tratar e mostrar essas informações visualmente.

Você percebe que dessa forma eu consigo seccionar e ter uma melhor divisão de tarefas para, por exemplo, o back-end ficar responsável por autenticação, por segurança, por comunicação com o banco de dados, por regra de negócios, enquanto o front-end fica literalmente responsável por mostrar isso na tela e aí imagine que você está disponibilizando o serviço por meio de endpoints, você faz essa requisição diretamente por um determinado endpoint onde o back-end vai fornecer meio que uma documentação para você em que fala, ó, Násser, quando você for requisitar produtos, requisite nesse endereço dessa forma aqui, mas se você quiser, por exemplo, requisitar quais são os usuários, você passa nesse endereço, você quer adicionar um novo usuário, vai no endereço de usuário e aí a gente começa a falar sobre API.
