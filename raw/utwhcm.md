# [UTwHCM] - Unit Testing With Hand Crafted Mocks

Este artigo resume e nomeia uma série de idiomas relacionados a **Hand-Built Test Doubles** (ver *Configurable Test Double*, página X), especificamente **Test Stubs** (página X) e **Mock Objects** (página X). Sven Gorts escreve:

> Muitos dos testes unitários que escrevi nos últimos anos usam mock objects para testar o comportamento de um componente isoladamente do resto do sistema. Até agora, apesar da disponibilidade de vários frameworks de mocking, cada uma das classes de mock que usei foi escrita à mão. Neste artigo faço uma retrospectiva e tento consolidar os idiomas de mocking que encontrei mais úteis.
