# test-driven bug fixing

Fonte original: xUnitPatterns.com — Glossário

Test-driven bug fixing é uma forma de corrigir bugs que consiste em escrever e automatizar um unit test que reproduz o bug antes de depurar o código e aplicar a correção. É a extensão do test-driven development aplicada à correção de defeitos.

Ver também: test-driven development, unit test.
